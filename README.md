# Отпуск мечты: что оставим за бортом?

Вся игра — один файл `index.html`. Три режима по одной ссылке:

| Кто | Ссылка | Что видит |
|---|---|---|
| Участники | `…/index.html` | вход по имени, личный выбор, текущая карточка, финал |
| Общий экран | `…/index.html#screen` | эту вкладку ты показываешь в Google Meet |
| Ведущая | `…/index.html#host` | пульт со статистикой (пароль в `CONFIG.HOST_PIN`) |

## 0. Проверить до всякой настройки (5 минут)

Открой `index.html` прямо с компьютера — без Firebase игра работает в тестовом режиме: каждая вкладка браузера — отдельный участник. Открой вкладку `#host`, вкладку `#screen` и 2–3 обычные вкладки и прогони всю игру сама.

## 1. Firebase (как в «Перевозчике» и «Деле №417»)

1. console.firebase.google.com → создай проект (или возьми старый).
2. Build → **Realtime Database** → Create database (регион Europe) → Start in **test mode**.
3. Rules → вставь и нажми Publish:
   ```json
   {
     "rules": {
       "otpusk": { ".read": true, ".write": true }
     }
   }
   ```
4. Project settings → Your apps → Web app (`</>`) → скопируй `firebaseConfig`.
5. В `index.html` найди блок `CONFIG` в начале скрипта и вставь значения `apiKey`, `authDomain`, `databaseURL`, `projectId`, `appId`. **Обязательно `databaseURL`** — без него игра останется в тестовом режиме.
6. Там же поменяй `HOST_PIN` на свой пароль.

## 2. GitHub Pages

Новый репозиторий → загрузи `index.html` → Settings → Pages → Branch: `main` → Save. Через минуту появится ссылка вида `https://<логин>.github.io/<репо>/`.

## 3. Перед встречей

1. Открой `…#host`, введи пароль, нажми **«Создать игру»**.
2. Открой `…#screen` в отдельной вкладке — именно её показывай в Meet (не пульт!).
3. Проверь с 2–3 коллегами с разных устройств: вход, выбор, что статистика видна только на пульте.
4. После проверки нажми **«Сбросить игру»** — всё обнулится, участникам нужно будет войти заново.

## 4. Сценарий встречи (60 минут)

**Вход (2–3 мин).** Покажи общий экран — на нём ссылка и бирки с именами тех, кто зашёл. Ссылку можно скинуть в чат Meet.

**Личный выбор (8 мин).** Пульт → «Начать личный выбор». У каждого 100 открыток по категориям, выбрать ровно 10, потом «Завершить» (два нажатия — защита от случайного клика). На общем экране таймер и «18 из 27 готовы».

**Статистика (5 мин).** «Закрыть выбор и открыть статистику». Участники видят заставку «Все готовы», ты — таблицу «сколько человек выбрали каждое впечатление».

**Обсуждение (~35 мин).** «Начать обсуждение». Дальше по кругу:
- в таблице нажми **«Обсудить»** у карточки → она появляется крупно на общем экране и у участников с подсказкой «Не согласен? Подними руку в Google Meet»;
- нет возражений → **«Исключить»** (на экране штамп «за бортом»);
- есть возражения → слушаете защитников → **«Оставить»** (у карточки появится якорь ⚓ «отстояли») или «Исключить».

Чтобы уложиться во время: 90 исключений по одному — это слишком долго. Используй **пакеты**: «Отметить все с 0 голосов» → «Предложить пакетом». Участники видят весь пакет; кто хочет спасти что-то — поднимает руку, ты нажимаешь «Оставить» именно у этой карточки, остальное — «Исключить все». Галочками можно собрать и свой пакет (например, «все про вечеринки»).

Передумали? Фильтр «За бортом» → **«Вернуть»**.

**Финал (12 мин).** Когда останется 10, на пульте появится «Открыть финал». Впиши название отпуска и нажми «Сохранить» — оно появится на экране. Каждый участник у себя видит «Из твоих 10 в общий отпуск попали: N». Кнопка «Показать совпадения на экране» выводит эти числа по именам — хороший момент для разговора «чьё желание победило». «Скачать итоговый список» — текстовый файл с 10 пунктами и всем, что ушло за борт.

## Приватность

Личные списки **нигде не хранятся**: при нажатии «Завершить» в базу уходит только +1 к общим счётчикам выбранных карточек. Поэтому ни ты, ни кто-то другой не может увидеть чужой список даже в консоли Firebase. Свой список участник видит только у себя в браузере.

## Если что-то пошло не так

- **Человек обновил страницу** — всё восстановится (выбор хранится в его браузере).
- **Человек зашёл с другого устройства, а имя «занято»** — на пульте в списке участников нажми ✕ рядом с именем, и он сможет войти заново. Если он уже завершил выбор, его голоса останутся в статистике.
- **Внизу красная плашка «Тестовый режим»** — не заполнен `databaseURL`.
- **«Нет доступа к базе»** — проверь правила Realtime Database (шаг 1.3).
- **Нужна вторая независимая игра** — поменяй `CONFIG.ROOT` (например, на `otpusk2`).
